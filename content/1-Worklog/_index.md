**On this page**, you will find the weekly work log detailing the tasks, objectives, and achievements completed during my internship with the **First Cloud AI Journey (FCAJ)**. 

Over the course of this 6-week intensive program, I focused on building cloud-native infrastructure, implementing secure user authentication, developing scalable backend APIs for game mechanics, and integrating generative AI with serverless performance optimizations.

Here is a summary of the weekly milestones:

**Week 1:** [Onboarding, Workshop Environment & Cloud Fundamentals](1.1-week1/)
Getting familiar with the FCAJ internship path, setting up essential workshop tools (Hugo, Markdown, VS Code, draw.io), and studying basic cloud computing concepts.

**Week 2:** [AWS Free Tier Account, Security Controls & Budgets](1.2-week2/)
Creating a secure AWS environment, claiming credit sponsorship, navigating the console, and configuring AWS Budgets for cost control.

**Week 3:** [AWS Core Storage, Databases & CLI Administration](1.3-week3/)
Implementing S3 static hosting, launching Amazon RDS instances, configuring DynamoDB tables, setting up CloudWatch Alarms, and managing resources via AWS CLI.

**Week 4:** [IaC Infrastructure Deployment & Cognito Authentication](1.4-week4/)
Using AWS CDK (C#) to automate infrastructure provisioning, compiling a shared library for backend-client parity, and configuring Cognito User Pools for secure user management and Silent Login.

**Week 5:** [RPG Loot Drop Algorithms & Inventory Backend APIs](1.5-week5/)
Designing game item models, coding a weighted random drop algorithm, building capacity-limited inventory APIs using C# Lambdas, and synchronizing player statistics to DynamoDB.

**Week 6:** [Generative AI RPG Narrative Integration & Lambda Performance Optimizations](1.6-week6/)
Integrating Amazon Bedrock (Claude) for dynamic storyline generation, diagnosing Lambda cold starts, and applying Native AOT & SnapStart optimizations to minimize latency.
