**On this page**, you will find the weekly work log detailing the tasks, objectives, and achievements completed during my internship with the **First Cloud AI Journey (FCAJ)**.

My internship is scheduled over a 2-month (8 weeks) timeline, focusing on the following milestones:

**Week 1:** [Onboarding, Workshop Tools & Cloud Fundamentals](1.1-week1/) (22/06/2026 - 27/06/2026)  
Connecting with team members, learning the 2-month training path, and setting up Hugo, Markdown, VS Code, and draw.io. Studying basic Cloud Computing concepts and AWS cost optimization.

**Week 2:** [AWS Environment Init & Basic Security Controls](1.2-week2/) (29/06/2026 - 04/07/2026)  
Enabling MFA for Root account, creating IAM users with Least Privilege. Learning Amazon S3, configuring access control and CORS. Installing AWS CLI, learning AWS CDK, and uploading game assets to S3.

**Week 3:** [Cognito Authentication & Game Databases](1.3-week3/) (06/07/2026 - 11/07/2026)  
Creating Cognito User Pools, programming authentication APIs (Register, Login, RefreshToken) on C# Backend connected to Unity. Designing the game database models and writing DynamoDB Repositories.

**Week 4:** [Amazon Bedrock AI Storyteller Integration](1.4-week4/) (13/07/2026 - 18/07/2026)  
Connecting C# backend to Bedrock AI, coding PromptBuilder, and processing JSON outputs from Bedrock to generate stories, player choices, and boss contexts dynamically.

**Week 5:** [Serverless Backend Architecture with Lambda & API Gateway](1.5-week5/) (20/07/2026 - 25/07/2026)  
Splitting C# business logic into AWS Lambda functions, configuring API Gateway, and optimizing Lambda memory and timeouts using dotnet publish.

**Week 6:** [Cloud Automation with Infrastructure as Code (AWS CDK)](1.6-week6/) (27/07/2026 - 01/08/2026)  
Defining the entire cloud infrastructure using AWS CDK (C#), dividing the infrastructure into multiple stacks, and practicing `cdk deploy`, `cdk synth`, and `cdk destroy`.

**Week 7:** [Security, Monitoring & Cost Optimization](1.7-week7/) (03/08/2026 - 08/08/2026)  
Moving sensitive configurations to Environment Variables, configuring CloudWatch Dashboards and Alarms, and analyzing costs using Cost Explorer.

**Week 8:** [End-to-End Testing & Project Handover](1.8-week8/) (09/08/2026 - 15/08/2026)  
Performing integration testing for all game features, evaluating the system against the AWS Well-Architected Framework, completing the internship report, and packaging source code.
