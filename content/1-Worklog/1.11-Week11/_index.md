### Week 11 Objectives:

* Learn about AWS DynamoDB for NoSQL databases.
* Master DynamoDB design patterns and optimization.
* Build real-time applications with DynamoDB Streams.
* Understand pricing and capacity planning.

### Week 11 Achievements:

* Gained comprehensive knowledge of DynamoDB as a fully managed NoSQL database service.

* Understood DynamoDB data model with partition keys and sort keys.

* Created DynamoDB tables with optimal partition key design for even data distribution.

* Configured Global Secondary Indexes (GSI) and Local Secondary Indexes (LSI) for query performance.

* Enabled point-in-time recovery and backup for data protection.

* Enabled DynamoDB Streams for capturing item-level modifications.

* Performed single-item and batch read/write operations efficiently.

* Implemented transactional reads and writes for ACID compliance.

* Used Query and Scan operations with appropriate filtering and projections.

* Optimized queries by leveraging indexes and avoiding full table scans.

* Configured Time-To-Live (TTL) for automatic item expiration.

* Built real-time applications using DynamoDB Streams with Lambda integration.

* Switched between provisioned and on-demand capacity modes based on workload.

* Implemented cost optimization strategies including reserved capacity.

* Monitored DynamoDB metrics and throttling using CloudWatch.
