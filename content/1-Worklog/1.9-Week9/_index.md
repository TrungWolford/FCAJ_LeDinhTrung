### Week 9 Objectives:

* Master CloudWatch for monitoring and observability.
* Learn about CloudWatch metrics, logs, and alarms.
* Understand application performance monitoring and troubleshooting.
* Explore X-Ray for distributed tracing and service mapping.

### Week 9 Achievements:

* Gained comprehensive knowledge of CloudWatch as the monitoring and observability service.

* Understood CloudWatch namespace, dimensions, and metrics hierarchy.

* Created custom metrics to track application-specific performance indicators.

* Built CloudWatch dashboards for monitoring multiple resources in real-time.

* Configured CloudWatch Logs for centralized log collection from EC2, Lambda, and other services.

* Created Log Groups and Log Streams for organizing application logs.

* Used CloudWatch Logs Insights to query and analyze log data.

* Created metric filters to extract metrics from log data.

* Created CloudWatch Alarms based on metrics for automated alerting.

* Configured SNS notifications for alarm events.

* Tested alarm scenarios and verified notification delivery.

* Configured AWS X-Ray for distributed tracing across microservices.

* Analyzed service maps to understand application dependencies.

* Troubleshot application issues using X-Ray traces and segments.

* Set up comprehensive monitoring and alerting for production applications.
